# Phase 33: 時間を1日ずつ進める

## 目的
時間が勝手に流れる仕組みをやめ、プレイヤーが割り当てを決めてから日を進めるようにする。判断の時間を急かさず、割り当ての良し悪しを1日ごとに見せる。

## 前提
Phase 32

## 決定済みの方針（2026-10-28 ユーザー回答）
- 「次の日へ」で1日進む。その日の作業は数秒のアニメーションで見せる（操作はブロックしない）
- 「判断が必要になるまで進める」ボタンも置く。担当待ち・期限切れ・新しい案件などで止まる

## やること
1. core に「1日進める」Command（例：`AdvanceDay`）を足し、内部は今の固定ステップで1営業日ぶん回す（日単位の仕組み：決算・倒産・解放・採用候補はそのまま）
2. 「判断が必要になるまで進める」Command。止まる条件は core の純粋関数にまとめる
3. 自動で時間を進めるループ・速度切替・一時停止・閉じている間の進行・区切りのカードをなくす。ループは描画（その日の進行のアニメーション）だけにする
4. HUD の時計を「○日目」と「次の日へ」「判断が必要になるまで」のボタンにする
5. セーブ形式を上げ、古いセーブは日の途中なら次の始業へ寄せて移行する

## テスト
- `tests/unit/`：AdvanceDay で1日進み、日単位の処理が1回だけ走る。判断が必要になるまで進めると止まる条件で止まる
- `tests/balance/`：自動進行の前提（実時間の何分・速度）を、日数の前提に表し直す。意図は変えない

## 完了条件
- [ ] ボタンを押さない限り時間が進まない
- [ ] 「判断が必要になるまで進める」が止まる条件で止まる
- [ ] `npm run check` が exit 0
