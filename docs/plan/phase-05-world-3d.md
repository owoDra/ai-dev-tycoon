# Phase 05: 2.5D ワールド・3Dモデル

## 目的
「現在の仕事の流れ」が一目で分かる、見下ろし2.5Dのオフィスを Three.js で描く。プレイヤーが最初に見るのはこの画面になる（企画書32章・61章）。

## 前提
Phase 03（ゲーム状態）、Phase 04（アセット基盤）

## ビジュアル方針
この Phase の見た目は**仮の既定値**とし、直後の D2 で比較して決める。そのため、カメラ・陰影の方式・アウトライン・キャラクターの形・流れの表現・ボトルネックの表現・環境は、すべて `content/look/world.ts` のプリセットから読み、実行中に切り替えられるようにする（`?dev=tweak` からも変更できるようにする）。配色は D1 の `content/look/visual.ts` に従う。

仮の既定値：
- 直交カメラによるアイソメトリック表示（約35°の俯角、45°の回転）。ホイールやピンチによるズームは一定の範囲内に制限し、パンも可能にする
- トゥーン調の陰影（`MeshToonMaterial` とグラデーションマップの WebP）、柔らかいアウトライン（反転ハル方式）、接地影（blob shadow のテクスチャ。リアルタイムシャドウは使わない）
- 床は角丸タイルのパステル調。工程ごとに「島」を作り、島どうしをコンベア（ベルト）でつなぐ
- Task は「光る小包（パケット）」としてコンベアを流れる。待ち行列は島の前に積み上がって見える

## やること
1. **追加モデルの生成**（`tools/assets/models/`）
   - 人間キャラクター：丸い頭とカプセル状の体を持つ抽象キャラクター。髪型・服の色・小物で3〜5種類の見分けがつくようにする
   - AI Agent：Research（アンテナとレンズ）、Code（ブラケット状のバイザー）、QA（盾の形の胸部）、Release（ロケットの背中）。ボディの形を変えて役割が分かるようにする
   - デスク、モニター、コンベアの部品、パケット、観葉植物、サーバーラックなどの小物
   - 表情（目・口）は小さなテクスチャアトラス（WebP）として作り、状態に応じて切り替える（通常・集中・困り・喜び）
2. **`world/` の構成**
   - `renderer.ts`：WebGLRenderer、`devicePixelRatio` の上限 2、リサイズ対応、**dirty フラグがあるとき・アニメーション中だけ描画**する
   - `camera.ts`：アイソメトリックカメラとズーム・パン（motion の spring でなめらかに動かす）
   - `layout.ts`：案件の Task 依存グラフから島の配置とコンベアの経路を計算する純粋関数（テスト対象）
   - `sync.ts`：ViewModel と Three.js のオブジェクトを差分同期する（ID をキーにして生成・更新・削除）
   - `actors.ts`：キャラクターの待機・作業・歩行・喜びのアニメーションを、ボーンを使わずに手続き的に作る（上下動・傾き・スカッシュ＆ストレッチ）
   - `packets.ts`：パケットの移動を InstancedMesh で描く
   - `picking.ts`：Raycaster で島・キャラクター・パケットを選択し、`SelectEntity` を発行する（選択状態は UI 側の state として持ち、core には入れない）
3. **`view/world.ts`**：GameState を WorldViewModel（島・アクター・パケット・ボトルネックの強度）に変換するセレクタ
4. **ボトルネックの表示**：島が脈動する、赤みのリングが出る、パケットが積み上がる。色だけで示さず、アイコン付きの吹き出し（Phase 06 の DOM オーバーレイ）でも伝えられるよう、ViewModel にフラグを用意しておく
5. **ワールド座標を画面座標へ変換するAPI**：DOM のラベルやポップアップを3Dオブジェクトの上に重ねるために使う（`world.project(entityId) → {x, y}`）
6. **性能**：draw call の上限を設けて計測できるようにする（開発時はオーバーレイで表示）。ジオメトリとマテリアルは共有する

## テスト
- `tests/unit/layout.test.ts`：島どうしが重ならない、依存の方向が左上から右下へ流れる、決定論的である
- `tests/view/world.test.ts`：Task の状態が ViewModel に正しく反映される（待ち行列の長さ・ボトルネックのフラグ）
