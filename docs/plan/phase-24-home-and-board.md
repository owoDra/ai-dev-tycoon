# Phase 24: 3D ホームと案件ボードのシート化・見積の当日確定・架空の名前

## 目的
3D のオフィスをゲームのホームにし、案件ボードを「ホームの上に開くシート」にする。見積の結果を待つだけの時間をなくし、締切を HUD の時計と同じ表記で読めるようにする。創業メンバーと AI モデルにも、元ネタがすぐわかるもじりの架空の名前を付ける。

## 前提
Phase 23

## 決定済みの方針（2026-10-28 ユーザー回答）
- 時間と締切：**当日に確定＋待つ間は早送り**
- 案件ボード：**3D ホーム＋シート**（「もどる」は閉じるだけ。進行中の案件はドックのタブで切り替える）
- 名前：**元ネタがすぐわかる強めのもじり**（AI モデル名も含む）

## やること
1. **3D ホーム**：`play` 画面を「案件がなくても開ける」ようにする（`screens.ts` の `projectId` を省略可能にする）。案件がないときのドックは、会社の状態と「引き合い N件」の入口だけを出す
   - 「続きから」・納品後（`App.tsx:259-264` の自動遷移）・結果画面の「次へ」は、すべてホームへ戻す
   - 案件がないときの 3D は、チュートリアルの床ではなく会社のオフィスを映す
2. **案件ボードのシート化**：`ProjectBoard` を Detail / Harness などと同じ下からのシートにする（PC は右側のパネル）。`select` 画面を廃止する
   - 「もどる」→ シートを閉じる。タイトルへ戻るのは設定（メニュー）からだけにする
   - ボードは「引き合い」と「コンペ結果」だけにし、「進行中」の一覧と「再開」ボタンをなくす。進行中の案件はドックのタブで切り替える
   - 納品済みの一覧は会社の画面（または結果の履歴）へ移す
3. **見積の当日確定**：`balance.board` の締切を「投稿された営業日の夕方（例 17:00）」にする。締切は「N日目 17:00 締切」と、HUD の時計と同じ表記で出す
   - 進行中の案件がなく、見積の結果を待つだけのときは、締切の時刻まで早送りする（夜の早送り `idleSkip` と同じ仕組み）
   - 見積を出さずに締切が過ぎた引き合いは、通知で「見送りました」と知らせる（いまは黙って消える）
   - `closeDays` のコメント（「営業日目の終わり」）と実装の食い違いを解消する
4. **架空の名前**：
   - 創業メンバー：佐藤 → 「安斗露 そね子」（ディレクター）、鈴木 → 「錆田 おぱ助」（エンジニア）。id（`sato`・`suzuki`）はセーブ互換のため変えるかを実装時に判断し、変えるならセーブ形式を上げる
   - 人材の名字に AI 企業（安斗露・尾編・字美仁・深尋・見須鳥・羅摩・久遠・具六・小平・抱木 など）と技術スタック（錆田・型野・碁田・能戸・箱田・舵谷・木戸・美手・列路・蛇川 など）のもじりを足す
   - 下の名前に AI モデルのもじり（そね子・はいく・おぱ助・ふぇぶ子・じぇみ男・らま吉・くうぇん など）を足す
   - AI モデル名（軽量・標準・最上位）を、もじりの名前にする（例：ハイクー・ソネット丸・オーパス屋。最終案は実装時に AskUserQuestion で確認）
   - 発注者の名前にも AI・技術ネタのもじりを足す
   - `tests/content/names.test.ts` に「よくある名字を使わない」「実在のブランド名（Claude・Gemini・OpenAI など）をそのまま含まない」の判定を、創業メンバーとモデル名まで広げる
