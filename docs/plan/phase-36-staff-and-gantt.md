# Phase 36: 社員一覧と、案件一覧・ガントチャート

## 目的
誰が何を掛け持ちしているか、どの案件が期限に間に合いそうかを一目で見られるようにする。

## 前提
Phase 35

## やること
1. 社員一覧：全員の担当中の工程・掛け持ちの数・その日の効率。状態は色に加えてアイコンとラベルで示す
2. 案件一覧とガントチャート：横軸が日、縦が案件。今日の線・期限の線・進み具合・見込みの終わり。案件を開くと工程の行を出す。炎上・期限間近をアイコンとラベルで示す
3. どちらも view のセレクタ（純粋関数）で作り、UI は読むだけにする。dist のサイズ予算を守るため、SVG ではなく素の要素で軽く描く

## テスト
- `tests/view/`：社員一覧・ガントの行の中身
- `tests/ui/`：シートが開き、案件の行を開くと工程が出る

## 完了条件
- [ ] 社員一覧とガントチャートが見られる
- [ ] `npm run check` が exit 0
