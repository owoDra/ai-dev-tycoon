# D4: 手触り（演出の強さ・音色）

## 決めること
Phase 07・08 で作った演出と音の「味付け」。

- 演出の強さ：控えめ / 標準 / 派手（Tier ごとの大きさ・長さ・パーティクル数・カメラの揺れ・フラッシュ）
- モーションの性格：きびきび（硬めの spring） / ぷるぷる（弾むような spring） / なめらか（イージング中心）
- 音色のパレット：例として、ウッド＆マリンバ（温かい） / シンセポップ（明るく電子的） / グラス＆ベル（きらきらして上品）
- BGM の曲調とテンポ、効果音と BGM の音量バランス

## 前提
Phase 08（演出と音のパラメータが `content/look/feel.ts` と `content/sfx.ts`・`content/music.ts` のプリセットに分かれていること）

## 探索で作るもの
- 演出の強さ3段階 × モーションの性格3種 × 音色のパレット3種を、それぞれ独立して切り替えられるプリセットとして作る
- **デモ再生**：Task 完了 → コンボ → 事件の発生 → 自動修復 → ボトルネックの解消 → Autonomy Streak → 案件完了、までを約60秒で自動再生するシーケンス（Tier 0〜4 を一通り体験できる）。再生中に切り替えると、その場で違いが分かるようにする
- 実際にプレイしながら切り替えることもできるようにする
- おすすめの組み合わせを3つ用意する

## 反映でやること
- 採用した組み合わせを既定値にし、不採用のプリセットを削除する。ただし設定画面の「演出の強さ」「音」の選択肢として残す価値があるものは、あなたの判断で残す
- `docs/decisions/D4-feel.md` に、採用内容・理由・あなたのコメント・URL を記録する
