# Phase 39: 評価基準を見えるようにする

## 目的
「何をすれば良い評価になるか」をプレイヤーが画面から読み取れるようにする。

## 前提
Phase 38

## やること
1. 納品のカード：利益の式（売上 − 人件費 − AI 費用 − 手戻り − その他 = 利益）と、利益 ÷ 人日 = 1人日あたりの利益、ランクの境目までの位置を出す
2. 評判の変化に理由を添える（納期内 +N・品質 Q% → ±M）。炎上・期限切れの減点も理由で示す
3. 案件ボードの引き合いに「評判が上がる条件」（納期内・品質の基準）を出す
4. 品質が一番低かった工程と、その任せ方を納品のカードに出す（次に直す場所）
5. 「評価のしくみ」の1枚の図（品質・納期 → 評判 → 受注額・昇格／利益 ÷ 人日 → ランク・決算）を会社の帯から開けるようにする
6. 「次の目標」カード：今の会社にとっての次の一手を1つだけ、理由と一緒に出す（view で決める純粋関数）

## 完了条件
- [ ] 納品のカードで利益の式・評判の理由・直す場所が見える
- [ ] 引き合いで評判が上がる条件が見える
- [ ] 評価のしくみの図と次の目標カードがある
- [ ] `npm run check` が exit 0
