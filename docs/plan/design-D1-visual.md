# D1: ビジュアルの方向性

## 決めること
ゲーム全体の画風。後続の Phase 04（トークン・アイコン・WebP）と Phase 05（3D）がこの決定に従う。

- 配色（Neutral の温度感、Primary とアクセントの色、彩度）
- 質感（影の柔らかさ、角丸の大きさ、アウトラインの有無と太さ、グラデーションの使い方）
- アイコンの画風（2トーン＋グラデーション / 太い線のフラット / ぷっくりしたクレイ調 など）
- 文字の階層（ウェイトとサイズの組み合わせ）

## 前提
Phase 01（Phase 02・03 と並行して進めてよい）

## 探索で作るもの
1. **探索用の基盤**（D2〜D5 でも使い回す）
   - `src/dev/explore/`：案の切り替えボタンを画面の隅に常に表示するシェル。選んだ案は URL ハッシュと localStorage に保存する（try/catch で囲む）
   - `?dev=tweak` の調整パネル：プリセットの値をスライダーや色選択で変更し、JSON としてコピーできる
   - `npm run build:explore`：探索用の単一HTMLを `dist-explore/index.html` に出力する（`verify:dist` と同じ検証を通す）
2. **プリセットの型**：`content/look/visual.ts` に `VisualPreset` 型を定義し、案A/B/C をその値として作る
3. **スタイルボード**（案ごとに同じ構成）
   - 背景とカード、ボタン（通常・ホバー・押下・無効）、HUD の見本（Profit/Human Hour・残り時間・稼働バー）
   - 状態表示（完了・注意・失敗。アイコンとラベル付き）
   - SVG アイコン8個程度（人間・AI・レビュー・Eval・Hook・お金・時計・警告）
   - オフィスの島の見本イラスト（SVG によるアイソメトリックの静止画。3Dの雰囲気を伝えるため）
   - 大きな数字の演出見本（「-6.4 人間時間」）
   - 各案のコントラスト比の自動チェック結果（AA を満たすか）を表示する
4. 案の方向性の例（違いがはっきりしていれば、この通りでなくてよい）
   - A：キャンディポップ（高彩度・太めのアウトライン・遊び心が強い）
   - B：ソフトクレイ（パステル・柔らかい多層の影・ぷっくりした立体感）
   - C：クリーンSaaS＋強いアクセント（落ち着いたニュートラル色に、1色の強いアクセント）

## 反映でやること
- 選んだ案（と調整値）を `content/look/visual.ts` の既定値にする。不採用の案を削除する（探索用のシェルと調整パネルは残す）
- `docs/decisions/D1-visual.md` に、採用した案・理由・あなたのコメント・比較ページの URL を短く残す
- コントラストのテスト（`tests/unit/contrast.test.ts`）を、採用した配色で追加する
