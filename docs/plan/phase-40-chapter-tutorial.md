# Phase 40: チュートリアルを章に分ける

## 目的
任せ方しか教えていない今のチュートリアルの後に、会社の運営の基本を、必要になったときに短い章で教える。

## 前提
Phase 39

## やること
1. 第1章（今のチュートリアル）の最後に「納品の結果の見方」を足す
2. 第2章「初めての受注」：案件ボードを開く → 引き合いの受注額・納期・評判の条件を読む → 受注 → 納品で評判が動く、を照らして案内する
3. 第3章「お金の流れ」：最初の給料日（人件費）に資金・人件費・AI 費用と、資金が尽きると倒産することを案内する
4. 第4章以降：昇格のたびに、その規模で増えるもの（掛け持ち・Seat・採用・Harness など）を短く案内する
5. 章はデータ（`content/`）で表し、進行は core が判定する。飛ばしても解放の進み方は変えない

## 完了条件
- [ ] 第1〜3章と昇格の章がデータで定義され、照らす場所と文言が出る
- [ ] 章を飛ばせる・飛ばしても進み方が変わらない
- [ ] `npm run check` が exit 0
