# D2: 2.5Dの見せ方

## 決めること
Phase 05 で作ったワールドの見せ方。**軸ごとに独立して切り替えられる**ようにし、組み合わせも試せるようにする。

| 軸 | 例 |
|---|---|
| カメラ | 正アイソメトリック（約30°） / 見下ろし強め（約50°） / 低め（約25°、奥行きを強調） |
| 陰影の方式 | トゥーン＋アウトライン / ソフトクレイ（簡易 AO・柔らかい影） / フラットなローポリ（面ごとの陰影がはっきりしたもの） |
| キャラクター | 大きな頭の2頭身 / 丸いブロブ型 / 幾何学的な形（積み木風） |
| 仕事の流れの表現 | コンベアとパケット / 道をキャラクターが書類を運んで歩く / 光るチューブの中を光の玉が流れる |
| ボトルネックの表現 | パケットの山とリング / 島の上の渋滞メーターとキャラクターの困り顔 / 煙と赤い脈動 |
| 環境 | 床の模様・壁の有無・小物の密度・時間帯による照明 |

## 前提
Phase 05（ワールドのパラメータが `content/look/world.ts` のプリセットに分かれていること）

## 探索で作るもの
- 上の各軸について2〜3案を `content/look/world.ts` のプリセットとして作る。キャラクターや流れの表現で新しいモデルが必要なら、`tools/assets/models/` で生成する
- おすすめの組み合わせを3つ（セットA/B/C）用意し、「セットで選ぶ」「軸ごとに選ぶ」の両方ができる比較ページにする
- ECサイト案件をヘッドレスで自動進行させ、ボトルネックの発生・解消が自然に見られるデモ再生を付ける（再生・停止・速度変更ができる）
- 各セットの描画負荷（draw call 数・フレーム時間の概算）を比較ページ上に表示する

## 反映でやること
- 採用した組み合わせを既定値にし、不採用のプリセットと使われないモデルを削除する
- `docs/decisions/D2-world-look.md` に、採用内容・理由・あなたのコメント・URL を記録する
