# Phase 32: 操作できなくなるバグ

## 目的
何かの操作の後にボタンが一切反応しなくなる・空の詳細表示が残る、という不具合をなくす。

## 前提
Phase 31

## 現状（2026-10-28 調査）
1. 島の詳細を開いたままホームへ移ると、退場中の詳細シートが空の案件 ID で view を読み直し（`workflowTasks` → `getProject('')`）、例外になる。Solid の更新が途中で捨てられて詳細シートが二度と出なくなり、ゲームループも `requestAnimationFrame` を予約し直さずに止まる
2. 開いているシートを開き直すと（`closeSheets()` → `setXOpen(true)` が batch されていない）、間で Presence の退場が始まり、止まらずに `opacity:0` のまま押せる要素が残る。案件ボードで起きると held のまま時間も止まる

## やること
1. シートの中で使う案件 ID は、ホームへ移った後も最後の案件のまま読む
2. ゲームループは例外が出ても次のフレームを予約する
3. シートの開き直しを batch でまとめる。Presence は退場中に値が戻ったら退場を止めて元に戻す

## テスト
- `tests/ui/SheetExit.dom.test.tsx`：退場を待たせた条件で、ホームへの移動で例外が出ない・開き直しで退場しない・Presence が退場を止める
- `tests/ui/loop.test.ts`：例外が出てもフレームを予約し続ける
