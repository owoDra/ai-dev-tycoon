# Phase 31: 節目の画面の間の通知とキー操作・メニューの NEW の印

## 目的
決算やあらすじなど、時間を止める画面を見ている間に、裏で通知が消えたり、キー操作が裏の画面に効いたりしないようにする。解放した機能が、メニュー側でも見つけられるようにする。

## 前提
Phase 30

## 現状（2026-10-28 調査。行番号は Phase 30 のコミット時点）
1. **通知のタイマーが、時間を止める画面の間も進む**
   - 短いお知らせは実時間の `setTimeout` で消える（`src/ui/notices.ts:35`）
   - 納品のカード（`src/app/App.tsx:286`）と用語のカード（`src/ui/play/TermCards.tsx:28`）も同じ
   - 時間を止める画面の判定は `src/app/App.tsx:219-226` の held（結果・設定・案件ボード・決算・倒産・区切り・あらすじ）。この間も上のタイマーは進むので、決算と同時に出た通知は画面の裏で消える
2. **時間を止める画面の間も、キー操作が裏のプレイ画面に効く**
   - キーは `window` で拾っている（`src/ui/play/PlayScreen.tsx:524-544`）。決算・あらすじ・区切りのカードの表示中も、Esc・矢印・Space が裏の島の選択やシートの開閉に効く
   - あらすじの表示中に Space（HUD の再開）を押すと、`PauseToggled` であらすじだけを閉じる（`src/app/App.tsx:251-254`）。`resume()` を通らないので、閉じていた間に締めた決算（`pendingFiscal`）が出ず、次の区切りで古い決算が突然出る
3. **NEW の印が担当カードにしかない**
   - 解放されたばかりの機能（`fresh`）は `src/ui/play/PlayScreen.tsx:144` の signal で、担当カード（`src/ui/play/AssignCards.tsx:148`）にしか印が付かない
   - Harness・Workflow Library・社員と Seat（採用）・Context など、メニュー側の解放には印がない（メニューは `src/ui/play/PlayControls.tsx`）
   - `fresh` は PlayScreen の中の signal なので、振り返りの画面へ行く・続きから再開すると消える

## やること
1. 通知・納品のカード・用語のカードのタイマーを、held の間は止める（残り時間を持ち越す）。時間を止める画面の判定は1か所にまとめて渡す
2. 時間を止める画面（決算・あらすじ・区切り・倒産・設定）が開いている間は、プレイ画面のキー操作を無効にする。Space であらすじを閉じるときも `resume()` を通し、`pendingFiscal` を出す
3. 解放したがまだ開いていない機能を state に持ち（セーブに残す）、メニューのボタン（Harness・Library・社員と Seat・Context）と担当カードに「NEW」の印を出す。開いた・使ったら消す。印はアイコンとラベルで示す（CLAUDE.md の設計ルール4）

## テスト
- `tests/ui/`：held の間は通知が消えず、解除後に残り時間で消える。決算の表示中に矢印キーを押しても島の選択が変わらない。あらすじの表示中に Space で再開すると、保留していた決算が出る
- `tests/unit/`：解放した機能に NEW が付き、開くと消える。セーブを通っても残る（セーブ形式を上げるならマイグレーションのテスト）
