# Phase 41: 画面をシンプルに分かりやすくする

## 目的
数字と通知を減らし、「一言 → 理由 → 数字」の順に見せる。何をすればよいかをホームで分かるようにする。

## 前提
Phase 40

## 決定済みの方針（2026-10-29 ユーザー回答）
- ホームの「今日やること」・任せ方のカードの3本のバー・メニューの2分割は案どおりに作り、最後にまとめて Artifact で確認してもらう

## やること
1. お知らせを3段階（要対応・お知らせ・記録）に分け、用語のカードを解放のカードにまとめる。同時に出す数を絞る
2. ホームに「今日やること」（判断が必要なもの3件まで。押すとその場所へ）を出し、次の目標カードをその先頭に置く
3. 数字を日本語にして減らす：「1人日あたりの利益」、ドックは納期・見込み利益・問題の3つ（稼働は詳細へ）、会社の帯は資金と次の目標
4. 任せ方のカードに「速さ・品質・人の手間」の3本のバーを出し、序盤はおすすめの印を1枚に付ける（Harness の解放で消す）
5. メニューを「会社」と「AI の仕組み」の2つにまとめる（中身が1つのうちはそのまま並べる）
6. 状態の色（人間・AI・利益・損・危険）をトークンで1か所に集める
7. 確認用のビルドを非公開の Artifact で公開する

## 完了条件
- [ ] 上の各項目が画面に出て、状態は色・アイコン・ラベルで示す
- [ ] `npm run check` が exit 0（サイズ予算内）
